Q6. Write a SQL statement to change the email column of employees table with 'not available' for those employees who belong to the 'Purchasing' department.

	

	UPDATE employees
	SET email = 'not available'
	WHERE department_id = (
    		SELECT department_id
   		FROM department
    		WHERE department_name = 'Purchasing'
	);
